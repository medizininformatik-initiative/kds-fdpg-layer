# Modul MTB

## Übersicht

Das Modul Molekulares Tumorboard (MTB) bildet die strukturierte Dokumentation molekularer Tumorboard-Entscheidungen ab. Es umfasst Profile fuer molekulare Diagnostik, Therapieempfehlungen, Biomarker und den klinischen Verlauf.

## Quellmodul

[MII KDS MTB](https://simplifier.net/packages/de.medizininformatikinitiative.kerndatensatz.mtb/2026.0.0)
